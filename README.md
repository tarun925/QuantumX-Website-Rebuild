# Onething local recreation

A local Next.js recreation of the visual structure and interactions of onething.design. It uses reusable templates and placeholder content for detail routes.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000. For a production build, run `npm run build` and then `npm start`.

The contact and newsletter forms demonstrate client-side validation and confirmation only; they do not transmit or store submissions. Project and content pages use a small sample data set and shared placeholder templates. The reference assets are stored locally in `public/assets`.
